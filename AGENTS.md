# Public thesis agent rules (13 November 2026)

Scientific integrity, safe publication and traceable provenance come first.

- Distinguish **real observed data**, verified official datasets, demonstration fixtures, mock/synthetic examples and unverified interpretations at every public claim and API output.
- Never imply a score (such as an F1 metric), anomaly finding, ground-truth event, pipeline run or live satellite API validation is reproduced unless the dataset, code, timestamp and exact command/run evidence support it.
- No confidential farm boundaries, proprietary imagery, personal identifiers, raw field/lab samples, internal sensors, access tokens, private keys, passwords or commercially restricted documents in this public repository, demo or GitHub Pages assets.
- Keep the approved thesis topic and supervisor requirements intact unless a documented academic decision changes them. A public commit or green offline test does not prove thesis approval, graduation, deployment or production reliability.
- Preserve reproducible tests and original evidence; prefer open upstream tooling with license/versions. Do not force-push, erase real-vs-demo provenance, or conceal failing tests.
- External emails, grant/application submissions and publishing private case-study material are consequential actions requiring explicit owner permission. Build safe local review artifacts without assuming sending authority.
