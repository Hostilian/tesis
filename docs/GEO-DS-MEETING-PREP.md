# Évora GIS / GEO-DS researcher discussion guide

Meeting status on 4 November 2026: **do not assume it is upcoming or happened without confirmation.**

Bring **only public or synthetic** WGS84 GeoJSON and an offline demonstration. Ask about a suitable orchard monitoring unit, native Sentinel-2 pixels versus canopy fraction, geographic reprojection and co-registration quality, field/block sample leakage, reliable cloud masking, seasonal confounding, published data sources, and how to independently adjudicate changes from annual RGB orthophotos. Ask for a minimum error/uncertainty reporting format (e.g., boundary shifts in metres, valid pixels, acquisition time gap).

Avoid sharing company fields/images until authorization; don't ask for full digital-twin engineering or imply existing validation. A useful outcome is one recommended public pilot dataset and a defensible holdout scheme.
